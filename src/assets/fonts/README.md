# Creation typography

`Creation.ttf` is a 700-weight Noto Sans JP subset containing only 創 and 造. It is served locally through Next.js font loading. The SIL Open Font License is included in `OFL.txt`.

Source: Google Fonts' official text-subsetting endpoint for Noto Sans JP.
Upstream: https://github.com/google/fonts/tree/main/ofl/notosansjp

The word 創造 (sōzō) means creation. Its use is an expressive reference to building software, rather than a claim about the author's language or nationality.

`Geist-OG.ttf` is a local copy of Geist Regular for social-preview rendering. Its license is included in `Geist-LICENSE.txt`.
